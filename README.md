# Church Ministry Schedule｜教會服事排班小幫手

純靜態網頁，透過 **GitHub Pages** 免費上線，資料存在 Firebase Realtime Database（免費 Spark 方案，新加坡）。

## 頁面
- `index.html`：排班主頁（排班同工使用）
- `reply.html`：同工回覆頁（所有同工使用）

## 功能
1. **分組回報與 LINE 分享**：一鍵產生每月詢問訊息（含回覆連結），可複製或直接分享到 LINE。
2. **排班與調整**：智慧自動排班（避開同天撞期、平衡次數；穩定優先、培養最後、暫停不排），可手動微調。
3. **閱覽與產出 JPG**：匯出 `.jpg` / `.png` 服事表。
4. **服事人力表**：以服事項目查看與調整人員。
5. **人力資料庫**：以人為單位管理服事狀況（穩定／培養／暫停）與服事項目，和服事人力表連動。

## 存取方式
- 程式碼裡**不含**任何同工資料，也不含資料存放位置。
- 資料位置由連結 `#` 後面的密碼決定，分成兩種連結：
  - **管理連結**：可檢視與修改全部內容，只給排班同工。
  - **回覆連結**：只看得到名字、服事項目與日期，只能送出回覆。
- 沒有連結打開網頁，只會看到提示畫面，讀不到任何資料。
- 兩種連結都可在主頁右上角「多人同步中」裡複製。

## 更新方式
修改檔案後推送到 `main` 分支，`.github/workflows/deploy.yml` 會自動重新部署。
